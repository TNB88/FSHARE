# Clip Drama Pro

Plugin CloudStream chuyển đổi từ addon Kodi `plugin.video.clipdramapro-2.1.0`.

- Nguồn dữ liệu: trang ReelShort tiếng Việt.
- Có trang chủ, nhiều danh mục, tìm kiếm, poster và mô tả.
- Hiển thị đầy đủ danh sách tập của từng phim ngắn.
- Phát luồng HLS (`.m3u8`) trực tiếp từ trang tập.
- Domain được đọc từ `domainclipdrama.txt` để có thể đổi mà không cần build lại plugin.

Mã nguồn Kotlin trong thư mục này được build bằng khung Gradle CloudStream chuẩn.
